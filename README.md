>
> - 官方最新稳定版本：[Stable Version](https://github.com/clash-verge-rev/clash-verge-rev/releases/latest)
> - 官方最新预览版本：[Autobuild Version](https://github.com/clash-verge-rev/clash-verge-rev/releases/tag/autobuild)

1. 前往 [GitHub Releases](https://github.com/Dragon1573/clash-verge-rev/releases) 页面，找到 [Daily](https://github.com/Dragon1573/clash-verge-rev/releases/tag/daily) 版本
2. 在最下方的 Assets 中，选择下载标记为 `Amd64 Windows EXE Installer` 的文件
3. 双击 EXE 启动安装程序

>
> 因为我只有 Windows `amd64` 环境设备，此 Fork 仅为自用， **不考虑** 提供除此之外的其他任何构建版本。
